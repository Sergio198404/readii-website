## How to update
1. Make changes to index.html
2. Update VERSION file (semantic versioning: MAJOR.MINOR.PATCH)
3. Add entry to CHANGELOG.md
4. Add session entry to WORKLOG.md
5. Archive previous version: copy old index.html to archive/index-vX.X.X.html
6. Deploy to Netlify

## Versioning rules
- PATCH (1.0.x): text edits, typo fixes, minor content updates
- MINOR (1.x.0): new sections, new features, layout changes
- MAJOR (x.0.0): full redesign or structural overhaul
